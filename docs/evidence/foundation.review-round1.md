## Integration blockers and smallest fixes

1. **P1 — The frozen revision ports cannot express the first save.** `src/domain/ports.ts:68–75,88–98` requires an existing nonnullable `{id,digest}` head for every commit, offers no create/init operation, and defines conflict results with a nonnullable current head. Import returns only a source document; arrangement returns a candidate. `CONTRACT.md:288–298` assumes the candidate can then be saved, but no exposed operation can atomically establish an absent head under the documented CAS/parent rules. Concrete check: `RevisionMutationSchema.safeParse({kind:'melody-edit', expectedHead:null, replacement:score}).success === false`; `kind:'create'` also fails. The required project/revision/parent identities in the engine's complete `ScoreV1` additionally lack an explicit allocation/stamping owner in these ports.

   **Smallest fix:** add a create operation (or discriminated create mutation with `expectedHead:null`) that requires an absent project head and `parentId:null`; retain existing CAS semantics for later edits. State which layer supplies/stamps project ID and immutable revision identity around the pure engine. Add a typed/schema-only first-save → approve → edit example and document create-on-existing rejection; leave actual storage/CAS execution in its named implementation gate. No new persistence framework or user approval step is necessary.

2. **P2 — The implemented download boundary contradicts its same-origin guarantee.** `src/domain/ports.ts:79–81` accepts any `downloadPath` beginning with `/`, while `CONTRACT.md:267–269,295` promises a same-origin download. With an otherwise valid manifest, all these paths parse successfully and resolve against `https://guitar.example` to `https://example.org/x.mid`: `//example.org/x.mid`, `/\\example.org/x.mid`, and `/\n/example.org/x.mid` (the last contains an actual newline). This is a directly exercised schema defect, not a missing endpoint feature.

   **Smallest fix:** use a shared local-download-path schema rejecting network-path references, backslashes, and control characters, with a normalized same-origin URL check where a base origin is available. Add positive `/artifacts/current.mid` and the three negative cases. Do not claim `startsWith('/')` proves same origin.
