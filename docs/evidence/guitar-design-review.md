Optional `finger` also cannot support a strict fingering proof. Freeze one runtime-validated, JSON-safe V1 schema and literal fixtures before splitting engine and renderer/API/UI work:

   ```ts
   type Q = { n: number; d: number }; // reduced safe integers; d > 0; quarters
   type Role = 'melody' | 'bass' | 'harmony';
   type SourceRef = { sourceNoteId: string; partId: number;
     barId: string; voiceId: string; beatId: string; noteIndex: number };
   type Sound = { id: string; role: Role; voiceId: string;
     start: Q; duration: Q; soundingMidi: number; source: SourceRef[] };
   type Placement = { soundId: string; stringIndex: 0|1|2|3|4|5;
     fret: number; finger: 0|1|2|3|4 }; // index 0 = low E; finger 0 = open
   type Occurrence = { id: string; writtenBarId: string; pass: number;
     start: Q; length: Q; entryBpm: number; meter: Meter };
   type ScoreV1 = { schemaVersion: 1; revisionId: string; digest: string;
     sourceManifest: SourceManifest; preferences: Preferences;
     instrument: InstrumentProfile; ability: VersionedAbilityProfile;
     bars: WrittenBar[]; tempos: TempoPoint[]; form: ExplicitForm;
     occurrences: Occurrence[]; sounds: Sound[]; rests: Rest[];
     notation: NotationSegment[]; placements: Placement[];
     handStates: HandState[]; locks: ApprovedLock[];
     changes: Change[]; planner: PlannerProvenance; approvals: ApprovalState };
   type ArrangeResult =
     | { status: 'candidate'; score: ScoreV1; diagnostics: Diagnostic[] }
     | { status: 'selection-needed'|'unsupported'|'unsatisfied'|'search-exhausted';
         diagnostics: Diagnostic[] };
   arrange(source: SourceScoreV1, request: ArrangementRequest): ArrangeResult;
   validate(source: SourceScoreV1, score: ScoreV1): ValidationReport;
   // ValidatedScoreV1 binds successful validation + approvals to score digest.
   project(score: ValidatedScoreV1): AdapterProjection;
   exportArtifact(score: ValidatedScoreV1, format: 'pdf'|'midi'):
     Promise<{ bytes: Uint8Array; manifest: ArtifactManifest }>;
   ```

   `Meter`, written bars, tempos, rests, instrument/profile, form, notation, locks and hand states are required concrete shared schemas, not worker-defined `unknown` escape hatches. Written-time `Sound` is one merged attack; notation segments reference that ID and carry spelling, voice, base duration/dots and explicit tuplet ratio/group. Expanded `(occurrenceId,soundId)` identities define playback; split notation must never create attacks. Source note IDs distinguish chord members and tie chains. Standard tuning is `[40,45,50,55,59,64]` low-to-high; TAB conversion uses `6-stringIndex`, and written guitar octave is explicitly separate from sounding MIDI. Restrict notation/time denominators to exactly representable adapter capabilities or return unsupported—no hidden rounding. `ArtifactManifest` binds revision/source/profile/adapter versions, digest and expected event/form counts. `AdapterProjection` keeps native alphaTab objects local and returns stable sound/segment/occurrence→beat/note/display mappings, including one-to-many ties and repeated passes. API/UI owns immutable revisions and approval invalidation; engine owns pure candidates/diagnostics; validator recomputes source melody locks and constraints, not merely trusts the candidate's report. Export endpoints revalidate the digest at runtime and cannot download stale or failed revisions. Unsupported constructs must have explicit diagnostics with bar/event IDs. This contract is a proposal to freeze, not implemented code.
